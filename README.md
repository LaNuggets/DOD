# DOD

The free communication app !

## Description

This is an instant messaging app.
That allow user to create channels, send messages, send images

## Recover project
```sh
git clone https://github.com/LaNuggets/DOD.git
```

## Installing

```sh
npm install
```

### Executing program

```sh
npm run dev
```
